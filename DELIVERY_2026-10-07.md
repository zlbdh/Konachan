## Outstanding Work and User Actions at Delivery

### A. APK Build (Local Sandbox AGP Issue; Use GitHub Actions)

The local AGP 8.9.0 task graph calculation threw `NoSuchElementException`. Plain Java compilation and project configuration worked; this was attributed to AGP compatibility with the sandbox. The report expected the standard GitHub runner to avoid this issue.

The requested setup steps were:

1. Open https://github.com/zlbdh/Konachan.
2. Select **Add file → Create new file**.
3. Use the filename `.github/workflows/build-apk.yml`.
4. Paste the workflow from `~/workspace/konachan/.github/workflows/build-apk.yml` and commit it.
5. Open **Actions**, wait for the build, and download the APK.

An alternative was to run `gh auth refresh -s workflow`, authorize in the browser, and then push the workflow file.
